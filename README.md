# Iris Classification CI/CD Pipeline

This project demonstrates a GitHub Actions workflow for training and evaluating machine learning models on the Iris dataset. Each push starts the workflow, which installs the Python dependencies, runs the training script, and posts a report to the commit with CML.

## What it does

The training script loads `iris.csv`, creates two additional ratio features, and splits the data into training and test sets. It trains and evaluates:

- Logistic Regression
- Random Forest Regressor (its numeric predictions are rounded to Iris class labels for classification metrics)

The script writes model scores to `scores.txt` and saves plots for a confusion matrix and Random Forest feature importances. The workflow combines those outputs into a report and publishes it as a CML commit comment.

## Project files

- `.github/workflows/run.yaml` — GitHub Actions workflow, triggered on pushes.
- `train_model.py` — data preparation, model training, evaluation, and plotting.
- `iris.csv` — Iris dataset used by the training script.
- `requirements.txt` — Python package dependencies.
- `ConfusionMatrix.png` — confusion matrix plot generated by the script.

## Requirements

- Python 3
- pip

The workflow runs on GitHub-hosted Ubuntu and installs the dependencies listed in `requirements.txt`.

## Run locally

Clone the repository and move into its directory:

```bash
git clone https://github.com/dhilleswar07/CICD_Pipeline_Workflow.git
cd CICD_Pipeline_Workflow
```

Install the dependencies and run the script from the repository root so it can find `iris.csv`:

```bash
python -m pip install -r requirements.txt
python train_model.py
```

The script creates `scores.txt` and `FeatureImportance.png`, and saves the confusion matrix as `ConfusionMatrix.png`. Matplotlib also displays plots when a graphical session is available.

## GitHub Actions workflow

The workflow in `.github/workflows/run.yaml` runs on every push. It checks out the repository, prepares the runner, installs the Python dependencies, runs `train_model.py`, and uses CML to publish the generated scores and plots as a commit comment. The workflow uses the repository-provided `GITHUB_TOKEN` secret for that comment.

To view a run, open the repository's **Actions** tab. A successful run should have a CML report comment attached to the triggering commit.

## Notes

- The dataset is read from the relative path `iris.csv`; run the script from the repository root.
- Model scores can vary between runs because the Random Forest model is not assigned a fixed random seed.
- The script currently reports Random Forest's `.score()` output, which is the regressor's R² score, alongside classification metrics computed from rounded predictions.
